# Public retail capacity scenario snapshot

VM records were retrieved for East US Linux D4as_v5 and E4as_v5 on 2026-10-23 UTC. The 20-GiB local profile requires a larger modeled application shape than the original 16-GiB D4as_v5; E4as_v5 is an explicit 4-vCPU/32-GiB planning assumption, not a measured Azure deployment. Separate AKS system nodes retain D4as_v5. Storage, AKS, IP and NAT snapshots are byte-for-byte copies of the earlier snapshot; each retains its original retrieval timestamp, URLs and checksums. No prices or bills were invented, and no Azure resources were deployed.
